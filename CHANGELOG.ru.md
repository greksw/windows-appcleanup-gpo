# История изменений по предоставленным файлам

Версии **восстановлены сравнением исходных файлов**, не из Git-коммитов. После обезличивания опубликованные файлы не выполнялись на Windows. У всех исторических копий запрещён `Enforce` для предотвращения случайного применения.

## v1.4 — точная идентичность Яндекс Музыки

- Добавлен точный Appx `Name`: `A025C540.Yandex.Music` (по результату инвентаризации на одной Windows 11).
- Уточнён комментарий; в лог добавлена версия `1.4` вместо `1.3`.
- Сохранились защита системных пакетов, Audit/Enforce, OneDrive opt-in и проверка `olk`.

## v1.3 — защищённый список Appx

- Расширен набор распознаваемых имён Xbox overlay/Game Bar, Copilot/Cortana, Office Hub, Outlook for Windows, видео/карт, People/Bing и SystemApps.
- Добавлены признаки `NonRemovable`, `IsPartOfSystem`, путь `Windows\SystemApps`: зарегистрировать `PROTECTED`, не удалять.
- Добавлено откладывание удаления нового Outlook при работающем `olk.exe`.
- Расширены поля журнала: версия, SID, версия сборки ОС и счётчики защищённых приложений.

## v1.0 — исходный user-scope audit/enforce

- Режим `Audit` по умолчанию, удаление через `Remove-AppxPackage` по точным `Name` только при `Enforce`.
- Запрет запуска от SYSTEM, пропуск серверов по умолчанию, пользовательский mutex и локальные журналы.
- Реестр HKCU — только инвентаризация; OneDrive per-user — отдельное подтверждение/ограничение.

## История CMD-запуска

Сохранены три CMD-версии, ссылавшиеся соответственно на v1.0, v1.3 и v1.4. Все производственные CMD вызывали `-Mode Enforce`. Публичные CMD-файлы изменены на `-Mode Audit`; не считать их точными копиями исходников.

## Изменения только публичной адаптации

- Скрыты внутренние имена организации, домена, устройств, путь NETLOGON и название GPO.
- Из журналирования HKCU исключены `UninstallString` и `QuietUninstallString`, поскольку там могут находиться чувствительные аргументы.
- Добавлен флаг подтверждения на `Enforce` для текущей копии; исторический `Enforce` запрещён.
