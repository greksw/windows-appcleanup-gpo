# Windows AppCleanup GPO — user-scoped Appx cleanup

[Русский](README.ru.md) · [Changelog](CHANGELOG.md)

This repository documents an October 2026 Windows 10/11 **user-scoped Appx inventory and cleanup** project implemented with User Configuration GPO logon scripts and PowerShell 5.1.

The complete bilingual documentation, anonymized v1.0/v1.3/v1.4 history, CMD wrappers, inventory helper and CI checks are being imported via a pull request.

**Public examples only.** Do not use directly on production endpoints: actual source identifiers are redacted, historical enforcement is disabled, and the current example requires an explicit acknowledgment before removal. The public launcher defaults to `Audit`. Windows Server/RDS is excluded unless separately approved. These files are not byte-for-byte copies of production scripts and have not been retested on Windows after redaction.
